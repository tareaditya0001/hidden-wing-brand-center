# Branding

The master company identity is Hidden Wing.

Description:

> Technology, products, solutions and digital ventures built under Hidden Wing.

## Visual system

- Navy `#1C3353`
- Gold `#C6A15B`
- Ivory `#F4EFE6`
- Font: Inter, system-ui, sans-serif

Logo files:

```text
src/frontend/hidden-wing-brand-center-web/public/assets/hidden-wing/
  logo.svg
  logo-dark.svg
  logo-light.svg
  icon.svg
  favicon.svg
  og-image.svg

```

`og-image.png` is a raster companion. Prefer the SVG sources when updating the mark.

## Product overrides

A product can override display name, logos, colors, font, and contact links. Empty fields inherit from the assigned or default theme and from company assets.
